# An example biological dissimilarity matrix

Pairwise Bray-Curtis dissimilarity calculated using the species
occurrence data from the
[`southwest`](https://mfitzpatrick.al.umces.edu/gdm/reference/southwest.md)
data set.

## Usage

``` r
gdmDissim
```
